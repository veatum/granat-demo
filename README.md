# Гранат — статическая демоверсия

Демонстрационный сайт кулинарии для портфолио Veatum. В проекте работают каталог, категории, корзина и формирование готового заказа в WhatsApp.

## Важно

- Все адреса, цены и позиции меню приведены для примера.
- Заказы не сохраняются и не поступают в кулинарию.
- Админка, база данных и серверные API в демоверсию не входят.
- Полная версия проекта может работать на VPS с SQLite, загрузкой фотографий и панелью управления.

## Запуск

```bash
npm install
npm run dev
```

Локальный адрес с учётом `basePath`: `http://localhost:3000/granat-demo/`.

## Проверка

```bash
npm run lint
npm run build
```

Статическая сборка создаётся в папке `out/` и публикуется на GitHub Pages.
