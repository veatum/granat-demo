# Granat Demo

Статическая mobile-first демоверсия сайта кулинарии для GitHub Pages. Next.js 16 App Router экспортируется в обычные HTML/CSS/JS-файлы.

## Правила

- Не добавлять backend, базу данных, админку, авторизацию и сбор персональных данных.
- Заказ формируется только на устройстве пользователя и открывается готовым сообщением в WhatsApp.
- Все цены, адреса и блюда должны быть явно представлены как демонстрационные данные.
- Не добавлять реальные данные клиента без отдельного запроса.
- Сохранять тёплую айдентику: кремовый фон, гранатовый акцент, домашняя кухня.

## Проверка

- Перед публикацией запускать `npm run lint` и `npm run build`.
- Проверять через реальный браузер на 375x812, 390x844, 768x1024 и 1280x800.
- Проверять категории, добавление и удаление позиций, корзину и сформированную WhatsApp-ссылку без отправки сообщения.
- Скриншоты QA хранить временно в `output/playwright/` и не коммитить.
